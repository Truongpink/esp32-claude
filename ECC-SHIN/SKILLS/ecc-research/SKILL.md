# Skill: ecc-research

1. Formulate the technical question and list constraints from the actual project.
2. Prefer official vendor specifications, source repositories and protocol documentation.
3. Check version compatibility with the project's ESP-IDF/toolchain and hardware target.
4. Cite sources and dates for external claims.
5. Separate documented specification, observed repository behavior and inference.
6. Present alternatives, trade-offs and a recommendation; do not add dependencies without approval.

# Skill: ecc-testing

1. Define expected behavior and acceptance criteria before testing.
2. Select the lowest-risk test that provides useful evidence.
3. Distinguish static inspection, unit tests, build, integration, runtime and physical-device tests.
4. Do not run GitHub Actions, CI, build, flash or OTA without separate explicit approval.
5. Record exact command/environment/result when execution is authorized.
6. Report untested dimensions and limitations; never infer hardware success from compilation.

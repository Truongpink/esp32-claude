# Skill: ecc-architecture

1. Trace the current implementation from entry points through modules, interfaces and persistent state.
2. Use source and configuration as primary evidence; use docs as supporting context.
3. Map data flow, control flow, network boundaries, storage and hardware interfaces.
4. Identify coupling, compatibility constraints and failure modes.
5. Mark undocumented or contradictory behavior BLOCKED rather than guessing.
6. Recommend the smallest architecture change and identify migration/test needs.

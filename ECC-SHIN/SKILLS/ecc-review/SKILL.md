# Skill: ecc-review

1. Review the complete approved diff against its stated task.
2. Check correctness, regressions, security, compatibility, maintainability and scope creep.
3. Inspect callers/interfaces and related tests where relevant.
4. Report findings by severity with exact file/line references when available.
5. Distinguish confirmed defects from questions and untested risks.
6. Confirm no unauthorized branch, CI, build, hardware or unrelated file changes occurred.

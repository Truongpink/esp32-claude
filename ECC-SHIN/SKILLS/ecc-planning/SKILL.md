# Skill: ecc-planning

1. Convert the request into a measurable outcome.
2. Identify in-scope and out-of-scope paths/components.
3. Inspect dependencies and existing behavior before planning edits.
4. List ordered steps, expected diff, risks and rollback considerations.
5. Separate source changes from tests, CI, build and hardware validation.
6. Request approval with exact paths and operations.
7. Do not begin unapproved work; revise plan if source differs from assumptions.

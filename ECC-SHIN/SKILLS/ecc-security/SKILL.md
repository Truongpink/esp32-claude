# Skill: ecc-security

1. Identify assets, trust boundaries, entry points and attacker capabilities.
2. Review secrets handling, authentication, authorization, transport security, storage and update paths.
3. Check logs, API responses, browser state, NVS and repository history for leakage risks without reproducing secrets.
4. Preserve TLS verification and least privilege.
5. Assess local Web Admin exposure and OTA integrity.
6. Classify findings by severity and evidence; propose minimal mitigations.
7. Obtain approval before security-sensitive changes or credential operations.

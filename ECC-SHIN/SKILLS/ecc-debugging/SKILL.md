# Skill: ecc-debugging

1. Capture the exact symptom, expected behavior, actual behavior and reproduction conditions.
2. Collect relevant logs, timestamps, configuration and source revision.
3. Trace the execution path and identify the earliest divergence.
4. Separate observed facts from hypotheses; rank hypotheses by evidence.
5. Propose a minimal diagnostic or fix and its side effects.
6. Ask approval before changing code, configuration or device state.
7. Do not claim root cause until evidence discriminates it from alternatives.

⬆️ Cập nhật Firmware OTA
Đang kiểm tra phân vùng...

Chọn file ChatAI-TPIOS-*-OTA.bin (application-only). Không chọn file USB-FLASH vì file đó chứa bootloader và partition table.

🛠️ Quản lý thiết bị

Chuyển về điểm truy cập cấu hình ChatAI-TPIOS (192.168.4.1) để chọn Wi-Fi khác.

Xóa Wi-Fi, API key và toàn bộ cấu hình đã lưu trong NVS. Sau đó thiết bị trở về chế độ cấu hình ban đầu.
